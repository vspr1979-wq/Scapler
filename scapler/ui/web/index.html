■ DEMO MODE — SYNTHETIC FIXTURE DATA · STUB BROKER · NO REAL ORDERS. This feed is generated locally for UI development; it is not market data and cannot arm live trading. Live mode requires broker credentials (Phase 6).
■ SHADOW MODE — LIVE DECISIONS, NO REAL ORDERS. Full stack runs on the real feed; every order is recorded in the journal at the prevailing quote (ask/bid) but is NOT sent to the broker. Go-live needs ≥3 clean shadow sessions + the go-live checklist (plan §12–13).
■ REPLAY — recorded real ticks. Replay can never arm the Signal agent in live mode.
